Your website is built.
Now let's connect it.

This package recreates the transportation website with an editable backend modeled on the Thrive PTO site. The public pages are ready to preview; GitHub and Cloudflare sign-in must be configured before editors can publish changes.

What you can edit:

All wording, service types, service descriptions, family story, logo, optional truck pictures, phone, email, brand colors, and form labels. Visitors can text, email, or copy their quote requests.

First steps

  1. Open the local homepage preview.
  2. Read the complete GitHub & Cloudflare setup guide.
  3. Upload this repository's files to its own new GitHub repository — not into Thrive PTO.
  4. Connect GitHub Pages, the Cloudflare OAuth Worker, and authorized editors.
  5. Upload the original business logo inside the new editor and verify the real phone number and email.
